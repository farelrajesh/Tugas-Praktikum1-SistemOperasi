2. Analisislah pada gambar kenapa saat instalasi perlu dipilih “/” pada opsi Mount Point?

Jawaban: Mount Point / digunakan karena / merupakan root directory atau direktori utama dalam Linux. Semua direktori dan file sistem Linux berada di bawah struktur /, sehingga partisi tersebut digunakan sebagai tempat utama untuk menginstal sistem operasi Ubuntu.

3. Berikan penjelasan tentang ext4, ext3, swap, ntfs, fat32,btrfs!

Jawaban:
-	ext4: Sistem file linux modern yang cepat, stabil, dan mendukuang journaling
-	ext3: Versi lama dari ext4 yang sudah mendukung journaling
-	swap: Ruang penyimpanan yang digunakan sebagai memori tambahan ketika RAM tidak mencukupi
-	NTFS: Sistem file yang umum digunakan Windows dan mendukung file besar serta fitur keamanan
-	FAT32: Sistem file dengan kompabilitas luas, tetapi memiliki batas ukuran satu file sekitar 4GB
-	Btrfs: Sistem file linus modern dengan fitur seperti snapshot dan pemulihan data
